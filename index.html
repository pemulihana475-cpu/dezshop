✅ Syarat & Ketentuan

  • Pastikan akun target tidak di-private.
  • Kesalahan input saat order pending/processing tidak dapat di-cancel.
  • Order baru untuk layanan & target sama, tunggu status sebelumnya selesai.

✅ Cara Melakukan Order

  • Pilih salah satu kategori & layanan.
  • Masukkan username / URL pada target.
  • Masukkan jumlah pemesanan.
  • Klik Order untuk memesan.
